# Mohamed Suhail S | Portfolio

Personal portfolio of Mohamed Suhail S, a Computer Science Engineering graduate
from Chennai, Tamil Nadu, working as a frontend developer, UI/UX designer and
digital marketer.

Live site: https://mohamedsuhail493.github.io/myportfolio/

## What's inside
- About, experience, projects, skills, certifications and education
- Light and dark themes, plus a colour switcher
- Skills filter, copy-email button, resume download and back-to-top button
- Fully responsive for phones, tablets and desktops

## Built with
HTML5, CSS3 and JavaScript. There is no framework and no build step.

## Run locally
Download the files and open `index.html` in a browser.

## Files
- `index.html`: the whole portfolio, with the photo built in
- `Mohamed-Suhail-Resume.pdf`: the resume download
